# ESP Studio v0.9.0-beta.1

**Status:** Release Candidate / first public beta  
**Tag (recommended):** `v0.9.0-beta.1`

Browser-only Web Serial studio for ESP8266 and ESP32. No backend. Architecture is frozen for this beta.

## Features

| Area | What ships |
| ---- | ---------- |
| Devices | Connect / disconnect over Web Serial; chip identify |
| Firmware Library | Browse built-in popular projects; deep-link Install |
| Flash | One-click install from catalog, GitHub releases, or local `.bin` |
| Serial Monitor | Live UTF-8 console + send text |
| Filesystem | Browse SPIFFS/LittleFS; upload/download (SPIFFS primary) |
| Diagnostics | Inspect device/environment/build; export `diagnostics.json` |
| Settings | Theme (session); About build metadata |
| Deploy | CI + optional FTP of `dist/` |

## Known limitations

- **OTA** is not implemented (sidebar entry explains this).
- Theme preference is **session-only** (not persisted).
- Firmware **install history** is not recorded.
- Identify does not yet expose chip revision / flash size / manufacturer.
- LittleFS **transfer** may return unsupported; browse remains best-effort.
- No auto-reconnect after unplug.
- No mid-flash cancel UX beyond leaving the page / disconnect.
- Firefox / Safari: **no Web Serial**.
- Hardware QA matrix rows may still be empty until community/manual fills.

## Supported boards

See [`docs/hardware-compatibility.md`](../hardware-compatibility.md).

**Chip families (software path):** ESP8266, ESP32, ESP32-S2, ESP32-S3, and mapped C2/C3/C6/H2 when esptool reports them.

**Browsers:** Chromium (Chrome / Edge / Opera) on HTTPS or localhost.

## Known issues

- Collapsed sidebar relies on tooltips; icon links now expose `aria-label`s.
- GitHub binary downloads need the Vite same-origin proxy in `pnpm dev` / `pnpm preview` (CORS).
- Default flash address `0x10000` may not match every ESP8266 layout.
- Concurrent Serial Monitor and Flash/Identify/Filesystem require stopping Serial first (exclusive transport ownership).

## Installation guide

### End users (hosted beta)

1. Open the deployed ESP Studio URL in **Chrome, Edge, or Opera**.
2. Use **HTTPS** (or localhost for local builds).
3. Connect a USB UART board, allow the serial port prompt, then use **Devices**.

### Developers (local)

Requires **Node.js ≥ 20** and **pnpm** (`corepack enable` recommended).

```bash
pnpm install
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173).

Quality gates:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

More: root [`README.md`](../../README.md) and [`docs/features/deployment.md`](../features/deployment.md).

## Troubleshooting

| Symptom | What to try |
| ------- | ----------- |
| “Web Serial not available” | Switch to Chromium; serve over HTTPS or localhost |
| Connect cancelled | Re-open Devices and approve the port picker |
| Device lost mid-session | Reconnect; check cable / USB power |
| Flash fails while Serial is open | Stop Serial Monitor, then flash again |
| Filesystem empty / errors | Confirm SPIFFS/LittleFS partition; try Refresh; LittleFS transfer may be unsupported |
| GitHub firmware won’t download (dev) | Use `pnpm dev` / `pnpm preview` so the asset proxy is active |
| Need a bug report package | Open **Diagnostics** → Export `diagnostics.json` (no serial logs / FS contents) |
